## 🎯 KEY RESPONSIVE CHANGES BY SECTION

### NAVBAR
| Breakpoint | Layout | Menu Type | CTA Visible |
|------------|--------|-----------|-------------|
| Desktop    | Horizontal | Inline links | Yes |
| Tablet     | Horizontal | Inline links | Yes |
| Mobile     | Hamburger | Slide-in menu | In menu |

### HERO
| Breakpoint | Layout | Avatar Size | Text Align |
|------------|--------|-------------|------------|
| Desktop    | 2-column | 380px | Left |
| Tablet     | 2-column | 320px | Left |
| Mobile     | Stacked | 240px | Center |

### ABOUT
| Breakpoint | Layout | Card Padding | Grid |
|------------|--------|--------------|------|
| Desktop    | 2-column | 20px | 2-col |
| Tablet     | 1-column | 16px | 1-col |
| Mobile     | 1-column | 14px | 1-col |

### CAROUSELS (Skills/Projects/Certs)
| Breakpoint | Cards Visible | Card Width | Arrows |
|------------|---------------|------------|--------|
| Desktop    | 3 (1+2 peek) | 560px | 48px |
| Tablet     | 3 (1+2 peek) | 500px | 44px |
| Mobile     | 1 (active) | 100% | 38px |
| Small      | 1 (active) | 100% | 36px |

### CONTACT
| Breakpoint | Layout | Form Width | Input Size |
|------------|--------|------------|------------|
| Desktop    | 2-column | 50% | Normal |
| Tablet     | 1-column | 100% | Normal |
| Mobile     | 1-column | 100% | Larger |

## 📐 SPACING SCALE

```
Desktop  → Tablet  → Mobile  → Small
100px    → 80px    → 60px    → 50px    (Section padding)
80px     → 60px    → 40px    → 32px    (Container padding)
48px     → 40px    → 32px    → 24px    (Element spacing)
24px     → 20px    → 16px    → 12px    (Card padding)
```

---

## 🎨 TYPOGRAPHY SCALE

```
Desktop  → Tablet  → Mobile  → Small
2.25rem  → 2rem    → 1.75rem → 1.5rem  (H1)
1.75rem  → 1.5rem  → 1.375rem→ 1.25rem (H2)
1.125rem → 1rem    → 0.9375rem→0.875rem(H3)
1rem     → 0.9375rem→0.875rem→ 0.8125rem(Body)
```
